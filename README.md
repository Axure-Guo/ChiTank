## 技术亮点

- 全原创：无图片资源，视觉基于 Axure 原生控件或 Emoji

- 多地图：取景随机窗，每局地图不同
- 完整道具系统：5 个道具，各有独立循环
- 还有更多彩蛋可以被探索
- 289 条认知洞察 + 72 项原创方法
